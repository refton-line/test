# STRATA — 3D-шахматы

Браузерная игра: классические шахматы 8×8 и формат «Strata» 5×5×3 на трёх слоях. ИИ играет в фоновом потоке, движок самостоятельный и не зависит от интерфейса.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # dist/ с отдельными ассетами
npm run build:single   # dist/index.html — один файл, открывается двойным кликом
```

## Профили ИИ

| Профиль | Глубина | Время по умолчанию | Разброс | Характер |
| --- | --- | --- | --- | --- |
| `legit` | 5 | 900 мс | ±55% | как человек: шумит в оценке, иногда ошибается, но мат не пропускает |
| `semi` | 9 | 1600 мс | ±25% | очень сильный, лёгкий шум |
| `blatant` | 18 | 3000 мс | 0% | без шума, играет лучший ход |

Каждому профилю отдельно настраиваются время, разброс и дебютный стиль (рандом или первая фигура заданного типа). Время на ход считается формулой:

```
budget = max(60, round(time * (1 + spread * (2 * u - 1))))   // u = Math.random()
```

## Бриллиантовый ход

Режим `brilliant` (`off` / `move` / `series`) заставляет ИИ искать жертву: ход, после которого фигура отдаётся под бой без защиты, но оценка остаётся в пределах 40 сантипешек от лучшего. `series` включает поиск на каждом ходу подряд, `move` — разово, `off` выключает. Найденный ход помечается в партии и показывается всплывающей подсказкой.

## Переиспользование движка

`src/engine.js` — чистый модуль без DOM:

```js
import {initial, legal, apply, search, evaluate, outcome} from './engine.js';

const state = initial('classic');   // или initial('strata')
const moves = legal(state);         // [{from, to, promotion?, castle?, ep?, double?}]
const next  = apply(state, moves[0]);
const {move, score, depth, nodes, candidates} = search(next, {
  time: 1000, maxDepth: 8, history: [state, next],
});
```

`search` возвращает лучший ход, глубину, число узлов, оценку и `candidates` — все корневые ходы с оценками, что позволяет строить свои профили выбора (см. `src/ai.js`).

`src/ai.js` — надстройка с профилями:

```js
import {chooseMove, PROFILES, thinkTime, isSacrifice} from './ai.js';

const result = chooseMove(state, {profile: 'blatant', brilliant: 'series', history});
// {move, score, depth, candidates, brilliant}
```

`src/ai.worker.js` — обёртка для Web Worker; её использует игра, а движок и профили можно запускать и в Node.

## Правила «Strata»

Три слоя 5×5. Ладья, слон, ферзь и король ходят в трёх измерениях, конь прыгает на (2,1) в любой плоскости, пешка рубит по трём диагоналям вперёд и может шагать на соседний слой. Шах, мат, пат, правило 50 ходов, троекратное повторение и недостаток материала — как в классике. Отмены ходов и подсказок нет.
